# Анализ и проектирование приложения Treffly

Учебный проект в рамках 3 курса бакалавра: анализ и проектирование мобильного приложения — от сбора требований до описания взаимодействия систем

## Моя роль
Технический писатель / аналитик в команде из 5 человек

## Задача
Существующие сервисы для поиска мероприятий перегружены лишней информацией и неудобны для локальных встреч. Приложение решает проблему организации досуга «здесь и сейчас», предоставляя единую платформу для создания событий, записи на них и визуального поиска мест проведения на интерактивной карте

## Что я сделала
- Разработала техническое задание по ГОСТ 34.602-2020
- Описала функциональные требования в виде US с AC, включая обработку ошибок и граничных случаев
- Смоделировала состояния системы (State Diagram)
- Описала взаимодействие компонентов (Sequence Diagram)
- Спроектировала сквозной бизнес-процесс создания мероприятия с учетом ошибок и отмены (BPMN 2.0)
- Оформляла баги с шагами воспроизведения и ожидаемым результатом в Jira
- Провела ручное тестирование интерфейса и логики работы приложения на Android
- Провела анализ пользовательских путей (User Flow)
