# User Stories

Список пользовательских историй с критериями приёмки (Acceptance Criteria).
Покрывают ключевые сценарии приложения: авторизация, работа с мероприятиями, 
управление мероприятиями, профиль.

## 1. Авторизация и регистрация

### US-01. Регистрация нового пользователя
**Как** неавторизованный пользователь,  
**я хочу** зарегистрироваться в приложении,  
**чтобы** получить доступ к полному функционалу

### US-02. Вход в аккаунт
### US-03. Восстановление пароля

## 2. Просмотр мероприятий

### US-04. Просмотр списка мероприятий

**я хочу** просмотреть список мероприятий,  
**чтобы** выбрать мероприятие для посещения

### US-05. Просмотр карты мероприятий
### US-06. Просмотр прошедших мероприятий
### US-07. Просмотр предстоящих мероприятий

## 3. Работа с мероприятием
